# Checkpoint 5 — Front-End Design

Este repositório reúne as atividades feitas para o Checkpoint 5: Revisão, Bootstrap, Tailwind e Vibe Code. A atividade de Vibe Code é uma landing page de fã sobre o Batman e Gotham City.

## Como abrir

1. Abra esta pasta no VS Code.
2. Abra `index.html` no navegador para ver o menu com as quatro atividades.
3. Escolha a atividade que deseja visualizar.

## Atividades

- `revisao/`: página da NovaCore feita com base nas referências da atividade de revisão.
- `bootstrap/`: página da Grão Nobre com menu, modal de compra, depoimentos, perguntas frequentes e rodapé.
- `tailwind/`: página do ateliê Fio & Prensa, com apresentação, etapas do trabalho, galeria, depoimento e contato.
- `vibecode/`: landing page do Batman, com fotos, navegação responsiva, galeria interativa e documentação do processo em `vibecode/docs/`.
- `referencias/`: imagens e orientações usadas como base para montar as páginas.

Bootstrap e Tailwind usam recursos carregados pela internet. A landing page do Batman também carrega suas fotografias e fontes de links externos, então é necessário estar conectado para que todo o conteúdo visual apareça.
