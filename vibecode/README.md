# Batman — O guardião de Gotham

Esta é uma landing page de fã sobre o Batman, feita para a atividade de Vibe Code da disciplina Front-End Design.

A ideia foi deixar a página com cara de pôster de filme: fundo escuro, vermelho nos detalhes, fotos do Batman, textos grandes e algumas informações sobre Gotham. Também coloquei uma galeria em que dá para clicar nas imagens para vê-las maiores.

## Como abrir

1. Baixe e extraia esta pasta.
2. Abra a pasta no VS Code.
3. Abra o arquivo `index.html` no navegador. Não precisa instalar nada.

As fotos são carregadas por links da internet. Por isso, é preciso estar conectado para que todas apareçam. Os links e as fontes estão em `docs/referencias-e-imagens.md`.

## O que tem na página

- Capa com uma foto do Batman e botões para navegar pela página.
- Parte sobre Bruce Wayne e a origem do personagem.
- Seção sobre Gotham e outra sobre os equipamentos do Batman.
- Imagens do Batman e do Batmóvel, com opção de ampliar.
- Menu para celular, animações leves e botão para acender o sinal.
- Documentação com o pedido feito à IA, referências e decisões de visual.

## Arquivos

- `index.html`: textos e estrutura da página.
- `styles.css`: cores, fontes, tamanhos e adaptação para celular.
- `script.js`: menu mobile, galeria, barra de leitura e botão do sinal.
- `docs/`: anotações do processo e links que usei como referência.

## Observação

É um projeto acadêmico de fã, sem ligação oficial com a DC ou a Warner Bros. Os personagens e as imagens continuam pertencendo aos seus respectivos donos. A página não tem finalidade comercial.
